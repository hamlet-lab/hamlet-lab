# Hamlet Lab

Building AiNIR: semantic trust boundaries for AI-generated program behavior.

AiNIR treats model output as a claim, not a fact. It explores how AI-generated
workflow semantics can be checked before lowering, handoff, or execution.

Current focus:

- semantic trust boundaries
- AI-generated workflow verification
- Trust Gate and TrustReceipt patterns
- negative conformance and replayable safety checks

Main project:

- [AiNIR](https://github.com/hamlet-lab/ainir) - v1.0 RC candidate public demo
